Windows 11 上で exe ファイルとインストーラーを作成する場合は、**Windows 側のコマンドプロンプト** から以下を実行してください。

1. **アプリのビルド (exeファイルの生成):**
```cmd
uv run scripts/build.py
```
2. **インストーラーの作成:**
Windowsに [Inno Setup](https://jrsoftware.org/isinfo.php) をインストールした後、`scripts/installer.iss` を以下のコマンドで実行します。
```cmd
"C:\Program Files\Inno Setup 7\ISCC.exe" scripts\installer.iss
```
