Windows 11 上で実際に exe ファイルとインストーラーを作成する場合は、**Windows 側のコマンドプロンプトや PowerShell から以下を実行** してください。

1. **アプリのビルド (exeファイルの生成):**
```cmd
set UV_PROJECT_ENVIRONMENT=.venv-win
uv run python scripts/build.py
```
2. **インストーラーの作成:**
Windowsに [Inno Setup](https://jrsoftware.org/isinfo.php) をインストールした後、作成された `scripts/installer.iss` を Inno Setup で開いてコンパイルするか、以下のコマンドを実行します。
```cmd
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" scripts\installer.iss
```
